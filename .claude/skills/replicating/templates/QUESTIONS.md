# Questions (only the necessary ones)

Doc limits:
- **Doc 2:** at most 2-3 clarifying questions, ideally none. Make sensible defaults otherwise. No questions about pricing, branding or business decisions.
- **Doc 1:** when the brief is ambiguous, either ask ONE clarifying question or deliver two distinct versions (A / B), never both.

Ask only when the analysis and the user's message leave it open:

1. **Product:** which product is this for? Ask only if it's unclear.
2. **What changes:** what is swapped in change (1)? Our product only, or also the environment / setting? If the setting direction is open, skip this question and deliver Version A / B instead.
3. **Mode:** doc 1 recreate+swap, or doc 2 from scratch? Ask only if the clip doesn't fit doc 1 well.
4. **Dialogue:** for doc 2 prompts with speech, what line is said?
